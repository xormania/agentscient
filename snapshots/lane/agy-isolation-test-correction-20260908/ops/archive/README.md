# ops/archive — House-era records, kept for reading, never for authority

Everything under this directory was written in the House lane about
the Python framework that preceded this project's Symfony shape, and
crossed at `99334f7` through `lane/workflow` (PR #10, closed unmerged;
I-008). It is reference for whoever writes a twin: the design thinking,
the plans, the review and skeptic reports, the ratifications of units
that were never built here.

Standing banner:

- Nothing here is law. `AGENTS.md`, `docs/`, and the register rule;
  where a page here disagrees, the page is the superseded reading.
- Nothing here is cited as authority by a contract, a test, or a
  check. A citation into this directory is a finding.
- Nothing here is edited. A correction is a new record elsewhere that
  names the page it corrects.
- Vocabulary here is the House's: `capability` where this project's
  law says `service`, unit numbers (U0, U1, U2) that name plans this
  project does not carry, and the House's dev-lane words throughout.
