# Concerns — single-concern reviewers as fixed artifacts

A concern is a reviewer that holds exactly one charge: one class of
defect, hunted across a change or a surface, by a stochastic worker
behind a deterministic shell.

## Pre-configured, never improvised

A concern is a tracked artifact — its prompt and dispatch settings —
identical run to run until deliberately modified, where every
modification is a reviewable diff. The artifact is supplied verbatim
as the dispatch job's scope input; the job template carries it, and
the job's output contract wins the seam between them.

## Findings are quotation pairs

A concern's finding quotes both halves: the declared words verbatim,
the practiced evidence verbatim, with the location of each. A
finding without both quotes is not a finding.

## Calibration

A stochastic check must still fire and stay quiet — as measured
rates, not intentions. Every concern carries a fixture set: planted
faults it must catch, clean neighbors it must pass. Its verdicts
report beside its rates, so "caught something" and "flaky reviewer"
are distinguishable readings, never a coin toss. A concern without
fixtures is a declared gap, visible, and outranks an imaginary
cover.

## The first concern

The hypocrisy concern: diff what is declared against what is
practiced, anywhere — contracts against tool behavior, statements
against statements, an actor's rules against that same actor's
record. It runs on everyone, the operator included, or it is itself
the hypocrisy it hunts.
