## The model

- `master` is the default and release branch; `dev` is the trunk.
  Sessions merge green PRs into `dev`; the owner alone merges the
  release PR from a branch cut off `master` with `dev` merged in.
- No squash, no deleted branches, no rewritten history. Draft first;
  ready is earned with a ready note.
- Every commit carries `Source:` and `Co-Authored-By:`; the commit-msg
  hook refuses a trailer git will not parse.
