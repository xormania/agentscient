## What broke, and how it was handled

- **The lane's own guard refused me twice**, both times on a clipped
  multi-alternation grep. Both refusals were right; the reads were
  re-taken in the counted shape.
- **Two instruments create their store on read.** `hand.py report` and
  `skills.py list` created `handwork.db` and `skills.db` under
  `~/.local/state/agentscient/` when run for the evaluation. The onboard
  contract guards against exactly this. Left in place, declared.
- **Serena rewrote the tracked project file on every start.** Cause
  measured at the pin: a legacy key migrated on load, then the file
  written back in full. Fixed in #12 by committing the form Serena
  writes; three starts on it were byte-identical.
- **Phpactor refuses a local config from an untrusted path.** The
  non-interactive flag is `config:trust --trust`; a worktree's first
  start records an explicit `false` for that path until it is run.
- **The PR overview refuses whole** when one PR reports no checks (#10).
  The doctor flags the user-level Stop hook as not executable although
  it is invoked through `python3` and runs.
- **Four paraphrases of the owner's intent were wrong** and corrected
  by the owner: that adopters would run the makers ("product feature"),
  that the lane was "parked", that a Python language server might
  return, and that Serena was out. Each correction is in the record
  above in the owner's words.

## Lessons

1. **The premise decides the overhead.** The imported lane was built
   for an owner who could neither plan nor read the code; the first
   evaluation judged it on its own terms and was half wrong. Ask what
   the owner can do before judging the machinery.
2. **Surveys invent.** Two of the packages the owner's documents named
   do not exist on Packagist. Every package on the plan was measured
   before it was cited.
3. **Label the standing of every statement.** RULED, AGREED, PROPOSED,
   OPEN. Three of the four corrections today were a proposal narrated
   as a decision.
4. **Commit what the tool writes.** A tracked file a tool normalizes on
   start is either committed in the normalized form or it is dirty in
   every checkout forever.
5. **Record the owner's words** (the previous report's lesson 2,
   confirmed again): paraphrase drift produced the four corrections.
