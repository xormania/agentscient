## What

The check-tests skeptic today writes a prose report to `out/SKEPTIC.md`
and the driver reads that file back. Its findings are not quotation pairs,
so the concerns contract ("a finding without both quotes is not a
finding") does not hold for the one reviewer that runs on every ladder,
and the findings ledger cannot sort them the way it sorts audit findings.
After this work order the skeptic returns its findings on the wire, as the
JSON envelope every other read job returns, and the driver validates that
envelope and keeps custody of it: the fix-tests stage receives a file the
driver wrote from a validated envelope, never a file the skeptic wrote.

## Contract

1. **Deliverable on the wire.** In `ops/devlane/task/jobs.json` and the
   row of `ops/devlane/task/CONTRACT.md`, `check-tests` delivers the JSON
   envelope on stdout: verdict, counts, and findings; `artifacts` is
   empty; no file is written. The prompt asks for exactly that.
2. **Findings are quotation pairs.** Each skeptic finding carries the
   declared words verbatim with their location, the practiced evidence
   verbatim with its location, and a reproduce command, in the same
   fields the audit jobs use (`docs/concerns.md`; the ledger schema in
   `ops/conductor/tools/findings.py`). Verdict is `changes` exactly when
   findings is non-empty.
3. **The driver validates the envelope at the check-tests stop.** Before
   the ladder advances, the driver checks: findings is a list of item 2
   shapes; counts agree with findings; verdict agrees with item 2;
   artifacts is empty. A violation stops the ladder with a refusal of
   class `envelope` on the wire naming the field, recorded as the stop
   reason; it is never retried as a flake.
4. **The driver keeps custody.** The fix-tests stage's input for the
   skeptic's findings is a regular file the driver writes under the
   ladder's inputs directory from the validated envelope, recorded with
   path and digest like every other input (`inputs_for`). The driver
   refuses to write through a symlink or outside the inputs directory
   (class `custody`), the P1 both 2026-09-04 audits raised against the
   earlier attempt.
5. **Read-role prompts ask for no undeclared file.** A read-role job in
   `jobs.json` whose prompt contains a positive instruction to write a path
   is refused at render (class `role`, naming the job and the sentence),
   unless that path is one of the job's declared outputs: a `file` row of
   the entry's `outputs` array, rendered under `{out}` as a required file
   (an entry without the array declares none). Recognition is by
   instruction shape (a write verb and a path-shaped token, negated
   sentences excluded), not by a list of forbidden words; the earlier
   attempt's `ops/devlane/task/write_path.py` is the candidate. The `plan`
   and `adjudicate` entries declare their outputs (`PLAN.md`, `RULING.md`)
   in the slice that lands the guard; `check-tests` declares none.
   Amended 2026-09-11 at the owner's word ("agreed - amend item 5 that way
   after slice 1 lands"), after the planner's finding F1: as first written
   the item would have refused the plan and adjudicate prompts at render,
   although the launcher makes a read job's out directory writable for its
   declared outputs by design.
6. **The ledger imports skeptic findings unchanged.** `findings.py import`
   already accepts check-tests records (`REVIEW_JOBS`, measured below);
   after item 2 those rows carry both quotes. No change to the import,
   the schema or the export.
7. **Refusals on the wire.** Every new refusal is one stderr line
   `class: expected …; found …; needed …`, exit 2, stdout empty, with one
   hermetic invocation added to the registry for each component that gains
   a refusal (`docs/wire.md` §Conformance).
8. **The 2026-09-04 findings are contract, not rediscovery.** The three
   findings the earlier attempt's audits raised (regular file inside the
   inputs directory, item 4; quotation pairs enforced not merely asked,
   items 2 and 3; shape-based read-role guard, item 5) are items here, so
   this ladder's audits measure them against the contract instead of
   finding them again.
