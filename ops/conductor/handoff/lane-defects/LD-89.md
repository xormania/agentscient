# LD-89 — an archive bundle limited to unique tips does not restore

- **class**: archive integrity
- **opened**: 2026-09-16 by the XO (PT-7)
- **status**: open as a standing rule; the mechanism is not built
- **measured**: 2026-09-16, against origin at dev d919c982

## The cheap form is broken

Archiving only the commits a branch holds outside the trunk is the obvious
saving. Measured over all 192 unique tips at origin:

| form | bytes | restores into an empty repository |
|---|---|---|
| `git bundle create <f> --all` | 12,077,986 | **389 refs, 3,432 commits** |
| `git bundle create <f> <tips> --not origin/dev origin/master` | 3,251,312 | **0 refs, 0 commits** |

The second carries prerequisites. `git bundle verify` names them —
d919c982 and ee13221d at the time of measurement — and a fetch into a fresh
`git init --bare` errors on each and restores nothing.

## Why it matters more than the 8 MB

The failure is silent at write time. The bundle is created without
complaint, it has a plausible size, and it sits in the archive looking like
insurance. It fails only when someone fetches it into an empty repository,
which is the moment after the branches it was meant to preserve are gone
from origin. A prerequisite-bearing bundle is not an archive; it is a diff
against a trunk that is free to move, be repacked, or itself be rewritten.

## The rule

Archive bundles are self-contained. Every one is verified by restoring it
into an empty repository and counting refs and commits **before** it is
written to the archive, and those counts are recorded beside it.

## Why this is a row and not an instruction in a scope

D-PATTERN-1: the fix is a mechanism, a refusal, a test with a planted fault,
or a record the next session reads. This row is the record; the mechanism is
still owed. The shape it should take: the archive lever refuses to write a
bundle whose restore into an empty repository does not return the ref and
commit counts it claims, so the proof is the write's precondition and not a
step someone remembers. Nothing implements that today.
