| defect | A dispatch stopped on purpose by its conductor and a dispatch whose harness died read identically to every reader. Measured 2026-09-16: the conductor launched author-tests on grok as record 20260916T092247Z-code-grok-15e30c at 09:22Z (launcher pid 886089, child 886610), then the owner overruled the scope, so the conductor sent SIGTERM to the launcher and, when the child outlived it, to the child. The record was left status=launched with no exit, no stderr, no envelope, and state.json still naming pid 886610. The watchdog reported it as harness gone after 2 min, pid dead, no exit written; the triage read lane, meaning a host fault in the grok process, and the Lead was about to file a lane defect and move the tests to another harness. Nothing in the record tells a deliberate stop from a death, so the lane can manufacture a false harness-fault history and route work away from a harness that never faulted. Confirmed by measurement the same day: `launch.py close` takes an id and nothing else (launch.py:2955-2956, the parser adds only `id`), so closing this record wrote status=died with the note `envelope-parse: no JSON object on stdout; DIED: process vanished without exit`. The conductor had no way to say otherwise, and the false reading is now the record's permanent content. |
| repair | the launcher gains a stop verb that marks the record stopped-by with the actor identity, the reason and the signal sent, so a conductor ending its own job writes that fact where the watchdog and the triage read it; the close verb is the likely home, since it already owns the record transition. Until then a record ended by hand cannot be told from a record whose harness died, and the triage table needs a row saying so. The absence is measured, not inferred: the close verb has no reason field to pass. |
| tests | none yet: the row is filed, not repaired. A row for it ends a launched record through the new verb and asserts the record reads stopped-by with the actor and the reason, with a clean neighbour where a harness that really died still reads as died. |
